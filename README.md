# Shop - ядро для интернет-магазина

## Репозиторий

Проект доступен на GitHub: https://github.com/profMoish/Shop

## Клонирование проекта

```bash
git clone https://github.com/profMoish/Shop.git
```

Перейти в папку проекта:

```bash
cd Shop
```

## Зависимости

Проект использует Poetry.

### Основные инструменты разработки

- `flake8` — линтер для проверки стиля кода
- `black` — автоформатирование кода
- `isort` — сортировка импортов

### Инструменты тестирования

- `pytest-cov` — измерение покрытия тестами
